# 小红书「作业榜」Backlog

> 项目性质：用 AI 做项目（Claude Code 实现）+ 含 AI 能力（评论聚类、AI 一句话总结）
> 阶段：场景 A（尚未上线，定义 MVP）
> MVP 范围状态：**已确认（2026-10-21）：#1–9 进本期**

## 核心假设 / 核心 Job

> 当我在看美食教程笔记、嫌博主做法太复杂时，我想一眼看到「大家实际做出来的样子」和「有没有更简单的做法」，以便决定我自己要不要跟做、跟做哪个版本。

要验证的一件事：**把评论区里的图片作业聚合成可浏览的「流派」后，用户是否比翻评论区更快找到适合自己的做法。**

## 名称备选（待选）

「作业榜」/「大家的作业」/「跟做墙」/「买家秀·做法版」 —— 原型暂用「作业榜」，名称为文案项，不阻塞。
